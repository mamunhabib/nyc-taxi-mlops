Traffic Simulator (Streamer Pod)

Decoupled pod continuously replaying 750 genuine Q2 NYC taxi rides (~2 req/s) against FastAPI to simulate real-world production load.

Centralized Observability (Elastic Stack)

K8s container runtime captures stdout/stderr from ALL cluster pods into host /var/log/containers/*.log. Filebeat harvests node logs → Logstash parses JSON → Elasticsearch indexes → Kibana visualizes (:8084).

Automated Drift Gate & Continuous Training (CT) Loop

Evidently AI monitors covariate shift. When feature drift ≥ 30%, Drift Gate automatically triggers the same Model Training runner pod (Step 7) to retrain on fresh MinIO data, promote the winning champion to MLflow (Step 8), and hot-reload FastAPI serving (Step 9) without downtime.
